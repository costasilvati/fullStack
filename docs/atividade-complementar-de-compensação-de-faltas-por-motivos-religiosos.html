Atividade Complementar de Compensação de Faltas por Motivos Religiosos

1. Contextualização e Objetivo

Em atendimento à solicitação de compensação de faltas por motivos religiosos às sextas-feiras, este documento estabelece as diretrizes e os critérios de avaliação para o acompanhamento dos conteúdos e a entrega das atividades práticas.

O objetivo desta compensação é garantir que o estudante desenvolva as competências e habilidades associadas ao conteúdo programático trabalhado em sala de aula, especificamente focado no Desenvolvimento de APIs com Node.js.

O material de referência teórica e prática para o acompanhamento da disciplina está disponível no e-book oficial: 👉 Link do Material: https://costasilvati.github.io/IntroNodeJS/

2. Instruções Gerais da Atividade

Para cada aula ministrada de forma presencial às sextas-feiras, o aluno deverá realizar o acompanhamento assíncrono dos conteúdos e cumprir o seguinte fluxo de trabalho:

  1. Acompanhamento dos Conteúdos: Estudar o tópico correspondente ao conteúdo trabalhado na semana de aula com base no e-book de referência e materiais complementares disponibilizados.
  2. Criação do Repositório:
    • Criar um repositório público no GitHub ou utilizar uma pasta dedicada dentro de um repositório já existente do estudante.
    • O repositório/pasta deve estar organizado por semanas ou tópicos de conteúdo (ex: semana-01/, semana-02/).
  3. Desenvolvimento da Atividade Prática:
    • Para cada conteúdo trabalhado na aula correspondente, o estudante deverá desenvolver uma aplicação/código prático original.
    • Regra do Código Prático: O código desenvolvido não pode ser uma cópia direta dos exemplos do e-book ou dos códigos de aula. O estudante deve criar um problema/cenário próprio, aplicando exatamente os mesmos conceitos e técnicas trabalhados no período.
  4. Submissão via Git e Prazo Semanal:
    • O estudante deve realizar os commits e o push dos códigos desenvolvidos no repositório do GitHub.
    • Os commits referentes à semana letiva devem ser efetuados impreterivelmente entre a sexta-feira e o domingo de cada semana de aula.

3. Cadastro do Repositório e Prazos do Processo

  • Cadastro do Link: O aluno deve enviar o link do repositório do GitHub por meio do formulário oficial no link a seguir:
    👉 Formulário de Cadastro: https://forms.gle/p1QRgmNYnRDFQdTP9
  • Prazo de Envio do Formulário: O envio do link no formulário deve ser feito em até 7 (sete) dias corridos a contar do recebimento destas instruções.

4. Avaliação e Registro Acadêmico

Após o término do prazo de envio do formulário, a compensação de faltas será processada mediante conferência semanal do repositório:

  1. Conferência das Entregas: A verificação das atividades será feita com base no histórico de commits (observando as datas entre sexta-feira e domingo) e no cumprimento do requisito de originalidade da aplicação prática em relação ao e-book.
  2. Lançamento de Faltas: A compensação de frequência será devidamente registrada no sistema acadêmico de acordo com o regulamento da instituição, após a conferência e validação do cumprimento das etapas descritas.
