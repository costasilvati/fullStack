### Instruções de Implementação

1. **Criar o Ficheiro**: No RStudio, clica em **File > New File > R Markdown...**, apaga o conteúdo padrão que aparece e cola o texto acima. Guarda como `atividade_compensacao_nodejs.Rmd`.
2. **Gerar o Documento (Knit)**: Clica no botão **Knit** no topo do editor para gerar o ficheiro final em **HTML** ou **PDF**.
3. **Usar no Google Forms**: Se quiseres passar estas tarefas práticas para o Google Forms, podes criar perguntas do tipo **"Resposta longa" (Parágrafo)** para que os alunos colem o código JavaScript e os JSONs de teste solicitados nas Tarefas 1, 2, 3 e 4.
